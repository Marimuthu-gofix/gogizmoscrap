BUYBACK PRICE SITE - HOSTINGER SETUP
====================================

The scraper (GitHub Actions, Render or your PC) posts prices to this API,
and the dashboard shows them.

1. In hPanel go to Databases > Management and create a MySQL database.
   Note the database name, user name and password. (An existing database
   works too: the tables are called buyback_prices and buyback_users.)

2. In hPanel File Manager open the site's public_html, upload the zip and
   extract it there. (Or let the GitHub deploy workflow upload the files.)

3. Open the site in a browser. It shows "Connect the database": type the
   database name, user and password and press "Test and save". The page
   checks the login, creates the tables and writes api/config.php itself.
   It also shows the API key (a new one, or the one already in config.php).

   By hand instead: copy config.example.php to config.php in this folder
   and fill in dsn, user, password and api_key. Make a key on your PC with:
       python -c "import secrets; print(secrets.token_urlsafe(32))"

4. Open https://YOUR-SITE/api/health in a browser. It must show
      {"status":"ok"}

5. On GitHub (repository > Settings > Secrets and variables > Actions) and
   on any PC that scrapes (.env file) set:
      PRICE_API_URL = https://YOUR-SITE/api
      PRICE_API_KEY = the api_key from step 3

The setup page only appears while api/config.php is missing, unreadable or
still has the example values. To run it again, delete api/config.php.
If the key ever leaks, change it in config.php and in the GitHub secret.
